# pi-command-panel

Fuzzy-searchable command panel for pi.

- `Ctrl+P` opens the panel from the main editor.
- Typing `/` as the first editor character also opens it.
- Filter commands by name and description; `↑`/`↓` navigate, `Tab` completes, `Enter` runs, `Esc` cancels.

## Usage

- `Ctrl+P`, or press `/` at the start of the input.
- `/panel` also opens the panel programmatically.

No configuration.
